[size=5][b]PalModManager v1.7.0 Changelog[/b][/size]
[b]Release Date:[/b] 2026-08-27

[size=4][b]Added[/b][/size]
[list]
[*] [b]Save Health Doctor & World Hub:[/b] Complete diagnostic and repair suite for Palworld savegames under the [b]Scan[/b] tab.
[list]
[*] Automatically discovers world saves across Steam, Xbox / Game Pass (WinGDK), and Linux Proton.
[*] Validates GVAS binary integrity and detects orphaned mod references causing startup crashes.
[*] 1-click automatic backup and save sanitizer to safely rescue corrupted or crashing saves.
[*] Backup snapshot history with side-by-side diff comparison, vanilla detection, and 1-click restore.
[*] Interactive inspection for [font=monospace]WorldOption.sav[/font] multipliers, player roster, and storage analytics.
[/list]
[*] [b]Deep Pak & UAsset Package Inspector:[/b] Pure-Rust inspection of [font=monospace].pak[/font] archives ([font=monospace]repak[/font]) and Unreal Engine binary assets ([font=monospace]unreal_asset[/font]).
[list]
[*] Explore virtual file trees directly in the Detail Panel and Mod Installer with instant search.
[*] Deep [font=monospace].uasset[/font] / [font=monospace].uexp[/font] inspector modal displaying export classes, import dependencies, and name table tokens.
[*] Added DirectDraw Surface (DDS) texture metadata inspection card with dimensions, mip levels, and DXGI format.
[/list]
[*] [b]Config Editor Enhancements:[/b] Smart auto-indentation on [font=monospace]Enter[/font], live cursor position ([font=monospace]Ln X, Col Y[/font]), folder state persistence, and unsaved changes indicator.
[*] [b]Expanded Syntax Highlighting:[/b] Added native syntax highlighting for [font=monospace].ini[/font], [font=monospace].cfg[/font], [font=monospace].toml[/font], [font=monospace].yaml[/font], [font=monospace].xml[/font], [font=monospace].py[/font], and [font=monospace].md[/font] files.
[*] [b]Automated Pak Compatibility Patch Engine:[/b] Detects colliding asset nodes across [font=monospace].pak[/font] mods and generates merged priority compatibility patches ([font=monospace]zzz_Patch_*.pak[/font]) with 1 click.
[*] [b]Xbox Game Pass & PC WinGDK Compatibility:[/b] Full detection and 1-click [font=monospace].utoc[/font] / [font=monospace].ucas[/font] table-of-contents generation ([font=monospace]retoc[/font]) for Game Pass mod support.
[*] [b]Altermatic / Dynamic Mod Alteration Engine:[/b] Framework integration for runtime alteration manifests and rule-based asset overrides.
[*] [b]Comprehensive Backend Logging:[/b] Added structured logs for mod installs, game launch, library management, and profile switches.
[*] [b]Full 6-Language Localization:[/b] Complete translation coverage across English, Spanish, Portuguese, Simplified Chinese, Japanese, and Korean.
[/list]

[size=4][b]Changed[/b][/size]
[list]
[*] Decoupled Config Editor syntax highlighting with [font=monospace]requestAnimationFrame[/font] and line-count gutter caching for fluid, lag-free typing.
[*] Compacted and optimized the preview card layout in the single-mod installer modal.
[*] Standardized dependency check logging for symmetrical output across UE4SS and PalSchema.
[*] Mod Installer and Detail Panel now allow direct inspection and exploration of [font=monospace].pak[/font] contents and binary asset metadata.
[/list]

[size=4][b]Fixed[/b][/size]
[list]
[*] Paused filesystem watcher during profile switching to prevent event storms and duplicate disk scans.
[*] Added a 60-second throttle to window focus checks to eliminate redundant rescans.
[*] Prevented redundant database disk writes when scanned mod data is unchanged.
[*] Fixed missing i18n translation import in profile management dialogs.
[*] Fixed toast notifications displaying behind modal overlays.
[/list]
