[size=5][b]PalModManager - Changelog v1.7.1 (2026-09-09)[/b][/size]

[size=4][b]Added[/b][/size]
[list]
[*] [b]In-Place Pak Tweaker & Binary Asset Editor:[/b] Directly inspect and modify cooked Unreal Engine properties and DataTable cells inside packed [font=monospace].pak[/font] mod archives without external tools.
  [list]
  [*] [b]Pristine Safety Backups:[/b] Automatically creates an untouched [font=monospace].original.bak[/font] copy before the first modification, guaranteeing 1-click rollback anytime.
  [*] [b]Interactive DataTable Grid Viewer:[/b] Dedicated tab displaying item stats, drop rates, and pal parameters in a clean searchable table with inline cell editing ([font=monospace]✏️[/font]).
  [*] [b]Live Blueprint CDO Comparative Diff:[/b] 5-column table displaying Property Name, Type, Vanilla Default, Mod Value, and 1-click reset to vanilla, showing exactly what a mod changes compared to the unmodded game.
  [*] [b]3-Way Noise Filter Toolbar:[/b] Switch instantly between [font=monospace][ 🎯 Editable Tweaks ][/font], [font=monospace][ ⚡ All Raw Deltas ][/font], and [font=monospace][ 📋 All Properties ][/font] to focus on what matters.
  [/list]
[*] [b]Dedicated Engine Development Resources Hub:[/b] Independent [font=monospace]🛠️ Dev Resources[/font] settings tab with an obsidian Master Manifest banner showing Steam Build ID, game version, and resource counts. Provides a unified 9-resource dashboard for Unreal Mappings ([font=monospace].usmap[/font]), C++ SDK headers ([font=monospace]Pal.hpp[/font]), property mappings ([font=monospace].jmap[/font]), and automated dump tools.
[*] [b]Per-Profile Mod Library Isolation:[/b] The Local Library now strictly respects your active profile. Mods installed in other profiles cleanly display as "Not Installed" with an active "Install to Profile" button.
[*] [b]Steam Workshop Integration Enhancements:[/b]
  [list]
  [*] Workshop library cards now show genuine mod version numbers from [font=monospace]Info.json[/font] instead of "unknown", eliminating spurious update warnings.
  [*] Workshop cards display per-profile installation state with dedicated "Install to Profile" and "Remove from Profile" (🗑️) buttons.
  [*] Safe removal guards Steam Workshop directories: removing a workshop mod detaches it from the active profile and unlinks runtime junctions without deleting the subscribed files from Steam.
  [*] Steam Workshop support is strictly restricted to Steam installations (cleanly disabled on Xbox / Game Pass).
  [/list]
[*] [b]Monaco Code Editor & IntelliSense:[/b] Full-featured in-app code editor with Palworld C++ reflection autocomplete, live game Blueprints autocompletion (>20,000 classes extracted directly from game paks), PalSchema DataTables & Row autocompletion (423 tables, 149k rows), live diagnostics dock, 1-click QuickFixes, and in-editor file/folder creation.
[*] [b]Custom Mod Notes:[/b] Write and save personal notes, load order reminders, and custom keybindings directly on any mod card via the detail panel and context menu.
[*] [b]Dual UE4SS Activation Mode:[/b] Choose between standard folder isolation ([font=monospace]enabled.txt[/font]) and direct [font=monospace]mods.txt[/font] control, with clean category formatting.
[*] [b]USMAP Reflection Explorer:[/b] Browse and inspect Palworld engine structs, classes, enums, and properties directly in the Database Inspector ([font=monospace]🗄 DB[/font]).
[*] [b]C++ SDK Manager:[/b] Manage and index Palworld SDK headers in Settings with 1-click cloud sync and local folder import.
[*] [b]Conflict Mitigation & Hotkey Tools:[/b] 1-click disable/edit actions on conflict cards and intelligent hotkey collision detection with automatic rebind recommendations.
[*] [b]Mod Packer Enhancements:[/b] Hierarchical tree-table file list view, Vortex folder preset, and 1-click dual packaging for Steam and Xbox.
[*] [b]Full 6-Language Localization:[/b] Complete translation coverage across all new tools, editor features, and menus (English, Spanish, Portuguese, Simplified Chinese, Japanese, Korean).
[/list]

[size=4][b]Changed[/b][/size]
[list]
[*] [b]Editor Canvas & Performance:[/b] Clean full-height editor workspace with native keyboard shortcuts ([font=monospace]Ctrl + S[/font], [font=monospace]Shift + Alt + F[/font]) and zero-latency mod switching.
[*] [b]Database & USMAP Performance:[/b] Significantly faster search response times, lower memory overhead, and smooth scrollable layouts.
[*] [b]Non-Destructive mods.txt Handling:[/b] Preserves custom comments, headers, and manual load orders cleanly during profile sync.
[*] [b]Codebase Optimization & Architecture:[/b] Modularized core subsystems to keep all source files lean, testable, and under strict line count limits.
[/list]

[size=4][b]Fixed[/b][/size]
[list]
[*] [b]Precise Line Navigation:[/b] Clicking "Edit" or "Preview" in diagnostics now jumps straight to the exact script line with a brief highlight.
[*] [b]Nexus Details Modal:[/b] Fixed unresponsiveness when clicking "Update Mod" on installed mods.
[*] [b]Engine Reflection & Hook Diagnostics:[/b] Improved C++ method parsing and eliminated false-positive warnings on Blueprint assets.
[*] [b]Steam Workshop & Profile Stability:[/b] Fixed 0-mod counts, toggle sync in [font=monospace]PalModSettings.ini[/font], Workshop PalSchema detection, and cross-profile state preservation.
[*] [b]Archive & Routing Handlers:[/b] Fixed installation errors for [font=monospace].7z[/font]/[font=monospace].rar[/font] files and corrected misrouted files for Hybrid and Altermatic mods.
[*] [b]Workshop Auto-Add Rescan:[/b] Prevented background mod scanners from automatically re-adding detached Workshop mods back into active profiles.
[*] [b]UI & Translations:[/b] Cleaned up bulk selection labels, deduplicated folder buttons, and resolved missing translation keys.
[/list]

[size=5][b]PalModManager - Changelog v1.7.0 (2026-08-31)[/b][/size]

[i]Thanks to the low volume of bug reports this past week, I had the dedicated time to tackle several things that were on my todo list and finish implementing them! Many of them are now implemented, though some have not been 100% field-tested yet. However, the core foundation for many new and very useful features is now ready.[/i]

[size=4][b]Added[/b][/size]
[list]
[*] [b]Full Altermatic & UniPalUI Framework Support:[/b] Complete out-of-the-box support for Altermatic runtime replacer mods and UniPalUI, automatically routing [font=monospace].pak[/font] files to [font=monospace]~mods/[/font] and configs to [font=monospace]SwapJSON/[/font], managing full physical enable/disable lifecycles per profile, and keeping [font=monospace]_LoadList.json[/font] synchronized automatically.
[*] [b]PMM World Backups Vault:[/b] Manage and restore PalModManager world backups with 1-click safety restoration.
[*] [b]Co-op Profile Packs:[/b] Export and import complete mod setups with dependencies and configs in a single [font=monospace].zip[/font] / [font=monospace].pmmprofile[/font].
[*] [b]Config Merge & Backup Diff:[/b] Visual side-by-side file comparison with smart merge that preserves custom settings during updates.
[*] [b]Dependency Version Vault:[/b] Archive and rollback UE4SS and PalSchema versions with 1-click, preserving mod configs.
[*] [b]PMM-Core Engine:[/b] Ultra-fast reactive framework with typed DOM elements and instant UI response times.
[*] [b]Download Speed & ETA:[/b] Live download speed ([font=monospace]⚡ MB/s[/font]) and remaining time in the Nexus queue.
[*] [b]Save Health Doctor:[/b] Detect and clean orphaned mod classes to fix loading crashes, with world settings inspector.
[*] [b]Deep Pak & UAsset Inspector:[/b] Pure-Rust inspection of [font=monospace].pak[/font] files, [font=monospace].uasset[/font] / [font=monospace].uexp[/font], and binary assets.
[*] [b]GPU Texture Inspector:[/b] View mod textures and images directly inside the app with channel filters and PNG export.
[*] [b]Library Mod Rollback:[/b] Keep older downloaded mod versions to rollback updates anytime with 1-click.
[*] [b]Nexus Creator Badges:[/b] Added Mod Author badge and total accumulated download counters.
[*] [b]Enhanced Code Editor:[/b] Auto-indentation, line/column counter, and syntax highlighting for various file formats.
[*] [b]Unreal Engine Schema Mappings (.usmap):[/b] Pure-Rust USMAP v4 parser and dynamic GitHub synchronization engine for deep cooked asset inspection and DataTable decoding with offline Steam ACF build detection.
[*] [b]Manual Compatibility Patch Builder (Beta):[/b] Resolve overlapping [font=monospace].pak[/font] asset collisions by selecting winning assets and compiling unified priority patches ([font=monospace]zzz_PMM_Patch_*_P.pak[/font]) with native [font=monospace]repak[/font] and [font=monospace]retoc[/font]. [i](Experimental testing; compatibility depends on mod structure and companions)[/i].
[*] [b]Conflict & Collision Scanner:[/b] Multi-layer detection of Pak asset collisions, PalSchema table collisions, and Lua hook collisions.
[*] [b]Xbox Game Pass (IoStore) Support:[/b] Built-in IoStore ([font=monospace].utoc[/font]/[font=monospace].ucas[/font]) conversion and detection.
[*] [b]Virtual Folder Startup Modes:[/b] Configurable folder behavior on startup (Expanded, Collapsed, Remember).
[/list]

[list]

[*] [b]Faster Startup:[/b] Streamlined initialization and eliminated background rescan lag.
[*] [b]Modular Codebase:[/b] Decoupled monolithic files into clean, maintainable domain modules.
[*] [b]Instant Settings:[/b] UI toggles now apply immediately without reloading.
[*] [b]Streamlined UI:[/b] More compact layouts for installer preview cards and savegame world lists.
[*] [b]Structured Logging:[/b] Standardized dual-layer frontend and backend logging.
[/list]
