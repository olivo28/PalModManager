[size=5][b]PalModManager v1.7.0 Changelog[/b][/size]
[b]Release Date:[/b] 2026-08-28

[size=4][b]Added[/b][/size]
[list]
[*] [b]PMM-Core Reactive Engine:[/b] Custom ultra-lightweight, Svelte-like reactive framework built specifically for PalModManager with zero Virtual DOM overhead, compile-time typed DOM elements, and instant UI response times.
[*] [b]Download Speed & ETA:[/b] Live download speed indicator ([font=monospace]⚡ 3.4 MB/s[/font]) and time remaining ([font=monospace]⏳ 42s[/font]) in the Nexus download queue.
[*] [b]Save Health Doctor & World Hub:[/b] Full Palworld savegame diagnostic and repair suite under the [b]Scan[/b] tab.
[list]
[*] Automatically discovers saves across Steam, Xbox Game Pass, and Linux Proton.
[*] Fixes startup crashes by cleaning orphaned mod data with 1-click automatic backups.
[*] Backup snapshot history with side-by-side diff comparisons and 1-click restore.
[*] Inspects world difficulty multipliers, player roster levels, and save analytics.
[/list]
[*] [b]Deep Pak & UAsset Inspector:[/b] Pure-Rust inspection of [font=monospace].pak[/font] files, Unreal Engine assets ([font=monospace].uasset[/font] / [font=monospace].uexp[/font]), and textures (DDS).
[*] [b]Nexus Mods Creator Badges:[/b] Added [b]✔ Mod Author[/b] badge and total accumulated downloads counter for mod creators.
[*] [b]Config Editor Upgrades:[/b] Smart auto-indentation, live cursor line/column counter, and unsaved changes indicator.
[*] [b]More File Syntax Highlighting:[/b] Added syntax highlighting for [font=monospace].ini[/font], [font=monospace].cfg[/font], [font=monospace].toml[/font], [font=monospace].yaml[/font], [font=monospace].xml[/font], [font=monospace].py[/font], and [font=monospace].md[/font] files.
[*] [b]Automated Pak Patch Engine:[/b] Detects conflicting mod assets and generates 1-click merged compatibility patches ([font=monospace]zzz_Patch_*.pak[/font]).
[*] [b]Xbox Game Pass (WinGDK) Support:[/b] Automatic detection and 1-click [font=monospace].utoc[/font] / [font=monospace].ucas[/font] table-of-contents generation ([font=monospace]retoc[/font]).
[*] [b]Altermatic Engine Support:[/b] Built-in support for dynamic alteration manifests and runtime mod asset overrides.
[*] [b]Virtual Folder Startup Modes:[/b] Added a new Interface setting to configure how mod folders behave on startup ([i]Always Expanded[/i], [i]Always Collapsed[/i], or [i]Remember Last State[/i]).
[*] [b]Cache Cleaner:[/b] Added [font=monospace]pnpm clean[/font] tool to easily purge intermediate build and compiler cache.
[*] [b]Full 6-Language Localization:[/b] 100% translated across English, Spanish, Portuguese, Simplified Chinese, Japanese, and Korean.
[/list]

[size=4][b]Changed[/b][/size]
[list]
[*] [b]Faster & Smoother Startup:[/b] Streamlined the application startup order for faster launch times and eliminated background rescan lag when switching windows.
[*] [b]100% PMM-Core Rollout:[/b] Completely modernized all app views and modals using the new Svelte-like typed architecture.
[*] [b]Modular Codebase:[/b] Restructured large monolithic files into clean, decoupled domain modules.
[*] [b]Instant Settings Updates:[/b] Visibility and behavior toggles now apply immediately without reloading the app.
[*] [b]Cleaner Mod Installer:[/b] More compact and balanced layout for preview cards and config diffs.
[*] [b]Faster Code Editor:[/b] Smooth, lag-free typing with asynchronous syntax highlighting.
[*] [b]Enhanced Logging:[/b] Standardized structured logging across all backend and frontend operations.
[/list]

[size=4][b]Fixed[/b][/size]
[list]
[*] [b]Filesystem Watcher:[/b] Paused file watchers during profile switches to avoid duplicate scans and event storms.
[*] [b]Database Write Hygiene:[/b] Prevented redundant database disk writes when mod metadata is unchanged.
[*] [b]Toast Notifications Layering:[/b] Fixed toast alerts appearing behind open modal dialogs.
[*] [b]Translation Cleanup:[/b] Cleaned up obsolete and duplicate translation keys across all language files.
[/list]
