[size=5][b]PalModManager - Changelog v1.7.2 (2026-09-22)[/b][/size]

[size=4][b]Added[/b][/size]
[list]
[*] [b]Interactive FOMOD Installation Wizard:[/b] Step-by-step modular assistant with image previews, MO2-style choice memory for updates/reinstalls ([font=monospace]🟢 PREVIOUSLY SELECTED[/font]), retroactive choice deduction from disk, multi-encoding support (UTF-16LE/BE, UTF-8 BOM), and tri-source consensus versioning.
[*] [b]TOS-Compliant Profile Sharing ([font=monospace].pmmprofile[/font]):[/b] Lightweight, copyright-safe profile export sharing only mod metadata, load orders, and user config deltas without redistributing third-party binaries. Includes a missing mods resolver with direct download links and an auto-applying floating helper.
[*] [b]Steam Workshop Bridge ("Artificial Workshop Mods"):[/b] Register local and Nexus mods directly into Palworld's native in-game Steam Workshop menu ([font=monospace]Mods/PalModSettings.ini[/font]).
[*] [b]Direct Nexus Mods Integration:[/b] Endorse, track, and manage mods directly from the app with instant local caching and new Tracked/Endorsed library filter tabs.
[*] [b]Save Health Doctor & GVAS Deep Scanner:[/b] Structural savegame validation against compiled engine catalogs to detect corrupted parameters, orphaned bases, and missing asset references, with atomic world repair and 1-click backup restore.
[*] [b]Real-Time UE4SS Log Viewer:[/b] Live streaming log viewer with severity filtering ([font=monospace]info[/font], [font=monospace]warning[/font], [font=monospace]error[/font], [font=monospace]crash[/font], [font=monospace]mod[/font]), search, line numbers, and direct navigation into the code editor.
[*] [b]Native Dynamic UI Scaling (100% Zero-Zoom):[/b] Fluid proportional scaling ([font=monospace]--ui-scale[/font]) across all views, dialogs, and Monaco editor with Settings slider (85%–140%) and universal hotkeys ([font=monospace]Ctrl +[/font], [font=monospace]Ctrl -[/font], [font=monospace]Ctrl 0[/font]).
[*] [b]Conflict Scanner ⇄ Monaco Editor Bridge:[/b] Scan diagnostics display directly in Monaco's Problems panel, and in-editor fixes automatically resolve scanner warnings in real-time with non-rotating immutable backups ([font=monospace].bak[/font]).
[*] [b]Headless Worker Process ([font=monospace]--pmm-worker[/font]):[/b] Dedicated background worker for heavy tasks like deep save scans and sanitization, keeping the interface completely fluid.
[*] [b]Reinstall Mod Context Menu Action:[/b] 1-click reinstall from the local library to easily re-trigger FOMOD wizards or restore pristine mod states.
[/list]

[size=4][b]Changed[/b][/size]
[list]
[*] [b]Clean-Slate Update Pipeline:[/b] Automatically snapshots user configurations and purges obsolete or renamed files from disk when updating directory-based mods (UE4SS and PalSchema), preventing duplicate schema conflicts.
[*] [b]Dynamic Zero-Recompile Resource Resolution:[/b] Engine catalogs and mappings now resolve dynamically from manifests and disk discovery without hardcoded build IDs.
[*] [b]Linux AppImage Optimization:[/b] Recompressed Linux AppImages with Zstandard (zstd) and removed redundant multimedia frameworks for a substantially lighter bundle.
[*] [b]Enhanced Scrollbars:[/b] Widened vertical scrollbars with high-contrast semi-transparent thumb styling across dark and light themes.
[*] [b]Active Mods Launch Logging:[/b] Launching Palworld logs an exhaustive, numbered list of active mods, versions, and types into [font=monospace]palmodmanager.log[/font] and console.
[/list]

[size=4][b]Fixed[/b][/size]
[list]
[*] [b]Same-Nexus-ID Mod Conflicts:[/b] Fixed false conflict detection blocking sequential installation and re-enabling of multi-file mods sharing the same Nexus page ID (e.g. Renamon body variants) by verifying physical disk identity.
[*] [b]Orphaned Config Files on Update / Clean Slate:[/b] Previous ghost configs are cleanly purged from disk and snapshots when a newer release drops bundled config files (e.g. SmartPause 1.3.14).
[*] [b]PalSchema Internal Files Misclassified as Configs:[/b] Excluded internal [font=monospace].json[/font] and [font=monospace].jsonc[/font] blueprint and table files inside PalSchema directories ([font=monospace]blueprints[/font], [font=monospace]tables[/font], [font=monospace]schemas[/font], [font=monospace]templates[/font]) from config archiving and diff alerts.
[*] [b]Cross-Platform Linux & SteamOS Stability:[/b] Replaced Windows drive letter backslash globs in asset scope with universal scope, eliminating startup crashes on Linux (Issue #12), fixed non-Windows game launching via official [font=monospace]steam://run/1623730[/font] URI, and decoupled AppImage [font=monospace]LD_LIBRARY_PATH[/font].
[*] [b]Xbox Game Pass Nested Content Directory:[/b] Canonical game root discovery automatically handles Microsoft Store wrapper layouts ([font=monospace]Palworld\Content\Pal\...[/font]).
[*] [b]Mod Library Rollback & Metadata Retention:[/b] Prevented Nexus API latest version from overwriting user-selected rollback versions, and prevented empty string overrides from wiping thumbnails, authors, and descriptions.
[*] [b]PalSchema Profile Sync:[/b] Fixed [font=monospace]PalSchema ✕[/font] false-uninstalled status when switching profiles via vault-aware sync and live runtime checks.
[*] [b]UE4SS Log Viewer Error Truncation:[/b] Large log files (>2000 lines) no longer discard early startup errors or crash entries during truncation.
[*] [b]Monaco Editor Ghost "Unsaved Changes":[/b] Keyed file buffers by [font=monospace]modId::filePath[/font] and purged buffers on mod uninstall, eliminating bogus unsaved changes alerts.
[*] [b]Floating Download Tray Positioning:[/b] Reanchored the NXM download tray to the bottom-left, keeping Monaco editor Save and Revert buttons fully accessible.
[*] [b]OAuth CSRF Security:[/b] Hardened Nexus OAuth callback with mandatory strict CSRF [font=monospace]state[/font] parameter verification.
[*] [b]Safe Hook Detection:[/b] Enhanced hook scanner to recognize defensive Lua wrappers ([font=monospace]safeRegisterHook[/font], [font=monospace]safeNotifyOnNewObject[/font]) without false positives.
[/list]

[size=5][b]PalModManager - Changelog v1.7.0 (2026-08-31)[/b][/size]

[i]Thanks to the low volume of bug reports this past week, I had the dedicated time to tackle several things that were on my todo list and finish implementing them! Many of them are now implemented, though some have not been 100% field-tested yet. However, the core foundation for many new and very useful features is now ready.[/i]

[size=4][b]Added[/b][/size]
[list]
[*] [b]Full Altermatic & UniPalUI Framework Support:[/b] Complete out-of-the-box support for Altermatic runtime replacer mods and UniPalUI, automatically routing [font=monospace].pak[/font] files to [font=monospace]~mods/[/font] and configs to [font=monospace]SwapJSON/[/font], managing full physical enable/disable lifecycles per profile, and keeping [font=monospace]_LoadList.json[/font] synchronized automatically.
[*] [b]PMM World Backups Vault:[/b] Manage and restore PalModManager world backups with 1-click safety restoration.
[*] [b]Co-op Profile Packs:[/b] Export and import complete mod setups with dependencies and configs in a single [font=monospace].zip[/font] / [font=monospace].pmmprofile[/font].
[*] [b]Config Merge & Backup Diff:[/b] Visual side-by-side file comparison with smart merge that preserves custom settings during updates.
[*] [b]Dependency Version Vault:[/b] Archive and rollback UE4SS and PalSchema versions with 1-click, preserving mod configs.
[*] [b]PMM-Core Engine:[/b] Ultra-fast reactive framework with typed DOM elements and instant UI response times.
[*] [b]Download Speed & ETA:[/b] Live download speed ([font=monospace]⚡ MB/s[/font]) and remaining time in the Nexus queue.
[*] [b]Save Health Doctor:[/b] Detect and clean orphaned mod classes to fix loading crashes, with world settings inspector.
[*] [b]Deep Pak & UAsset Inspector:[/b] Pure-Rust inspection of [font=monospace].pak[/font] files, [font=monospace].uasset[/font] / [font=monospace].uexp[/font], and binary assets.
[*] [b]GPU Texture Inspector:[/b] View mod textures and images directly inside the app with channel filters and PNG export.

[*] [b]Nexus Creator Badges:[/b] Added Mod Author badge and total accumulated download counters.
[*] [b]Enhanced Code Editor:[/b] Auto-indentation, line/column counter, and syntax highlighting for various file formats.
[*] [b]Unreal Engine Schema Mappings (.usmap):[/b] Pure-Rust USMAP v4 parser and dynamic GitHub synchronization engine for deep cooked asset inspection and DataTable decoding with offline Steam ACF build detection.
[*] [b]Manual Compatibility Patch Builder (Beta):[/b] Resolve overlapping [font=monospace].pak[/font] asset collisions by selecting winning assets and compiling unified priority patches ([font=monospace]zzz_PMM_Patch_*_P.pak[/font]) with native [font=monospace]repak[/font] and [font=monospace]retoc[/font]. [i](Experimental testing; compatibility depends on mod structure and companions)[/i].
