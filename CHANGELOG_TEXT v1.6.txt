PalModManager - Version 1.6.2 Changelog (2026-25-08)

[1.6.2] - 2026-08-25

Added
- Universal DoH Image Fallback: Multi-stage DNS (Cloudflare / Google) to bypass ISP image blocks and cache thumbnails locally.
- Network & Sources Tab: New Settings tab for DNS resolver preferences, image cache cleaner, and official dependency links.
- Library Filters & Sorting: Filter by install status (Installed, Not Installed, Updates) and sort by Name, Status, or Date.
- Native 7-Zip & LZMA Engine: Pure-Rust archive decompression for .7z and .zip, fixing extraction errors on Windows 10/11.
- Official PalSchema Logo: Added official branding provided by Okaetsu.

Fixed
- Fixed "View Source" buttons in Settings not opening URLs in default browser.
- Added ESC key shortcut to close the image Lightbox and mod details modal.
- Fixed 401 token expiration errors in Discover tab with automatic session recovery.
- Fixed image flickering and broken placeholder icons caused by unresolved asset paths.
- Improved automatic detection for PalSchema data mods.

------------------------------------

[1.6.1] - 2026-08-25

Added
- Storage & Cache Management: Disk storage inspector and cleaner in Settings (Safety & Backup) to view real-time space used by Temporary Downloads and the Local Mod Library, with 1-click cache purge and folder quick-access.
- Installed Status Badge in Mod Details: Active "Installed (vX.Y.Z)" badge in Discovery mod details when inspecting a mod already present in the manager.
- Full 6-Language Localization: Complete translations across EN, ES, PT, ZH-CN, JA, and KO for storage controls and notifications.

Changed
- Direct CDN HTTP Download Stream Handling: Download pipeline now supports direct HTTP/HTTPS CDN endpoints alongside nxm:// URLs for seamless 1-click Premium downloads.
- Windows File Lock Release: Added immediate file flushing and handle release upon download completion to prevent OS file write locks.
- Optimized Update Modal Dimensions: Expanded and balanced modal width to comfortably fit update notes and config diff tools.

Fixed
- Fixed runtime ReferenceError during version comparison that caused the installation modal to hang indefinitely on "Analyzing mod structure..." during updates.
- Resolved duplicate single-instance plugin initialization that was causing unexpected app closures on startup.
- Fixed flexbox shrink glitch on the update modal preview card, preventing it from squishing horizontally.
- Ensured Discovery details modal cleanly dismisses when triggering an in-app download.

------------------------------------

[1.6.0] - 2026-08-24

Added
- Nexus Mods Discovery Tab: In-app browser with live search, categories, tag filtering, and 1-click mod installation.
- Rich Mod Details Modal: Formatted BBCode/HTML descriptions, file categories, virus scan badges, and changelogs.
- Full Nexus SSO Integration: 1-click OAuth login with avatar display and persistent synced metrics.
- Native NXM Download Handler: Direct 1-click downloads from Nexus Mods with a real-time download queue tray.
- Lua Config Smart Merging: Preserves custom user keybindings and settings in .lua configs during mod updates.
- Protocol Association: Register and toggle nxm:// protocol handling directly from settings.

Changed
- Improved zip extraction and layout sanitizer to prevent flattening internal mod folders.
- Enhanced multi-component mod directory quick-access buttons (UE4SS, PalSchema, Pak, LogicMods).

Fixed
- Fixed PalSchema zip extraction to preserve 000_ load-order folder prefixes correctly.
- Resolved UE4SS nested path duplicates on full game directory archives.
- Masked sensitive OAuth tokens in the Database Inspector.
- General UI contrast, scrollbar visibility, and theme alignment improvements.
