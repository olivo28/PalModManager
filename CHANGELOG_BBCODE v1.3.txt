[size=5][b]PalModManager - Version 1.3.0 Changelog (2026-08-05)[/b][/size]

[hr]

[size=4][b]Added[/b][/size]
[list]
[*] [b]Build & Package Tool (Mod Packer)[/b]: Added a new [b]Build[/b] workspace tab inside the manager, allowing creators to organize, structure, and bundle mod files into clean, compliant archive formats.
  [list]
  [*] [b]Visual Projects Hub (Dashboard)[/b]: A dedicated grid workspace representing stashed mod packaging projects as folders (📁). Supports creating, double-click loading, renaming, and deleting stashes.[/*]
  [*] [b]Auto-Scanning Directory Stashing[/b]: Persists source directories and file paths along with target overrides instead of flat file snapshots. Re-scans active local directories automatically upon load, picking up new files seamlessly.[/*]
  [*] [b]Staging Tree Drag & Drop[/b]: Visual List View and Collapsible Tree View of staged files, allowing files to be dragged and dropped into parent folder nodes to re-arrange their destination paths inside the archive.[/*]
  [*] [b]Auto-Structuring Heuristics[/b]: Automatically organizes loose files into compliant folder layouts based on Mod Type (UE4SS, PalSchema, Pak, LogicMods, Hybrid) and name (e.g. mapping Lua to Mods/<mod_name>/Scripts/ and Pak to Pal/Content/Paks/~mods/).[/*]
  [*] [b]Standardized Metadata Generator[/b]: Automatically generates a standard modinfo.json metadata file containing Name, Version, Author, and Description.[/*]
  [*] [b]Multi-Format Archiving[/b]: Compresses the final workspace into clean, correctly structured .zip (natively in Rust), .7z, or .rar (utilizing system CLI tools) files.[/*]
  [/list][/*]
[*] [b]Mod Conflict & Compatibility Scanner[/b]: Added a new [b]Scan[/b] tab that analyzes enabled mods to identify table collisions (PalSchema row overrides) and hook overlaps (multiple mods hooking the same engine function in Lua).
  [list]
  [*] [b]Side-by-Side Split View[/b]: Renders Lua hook conflicts on the left and PalSchema table/row overlaps on the right as collapsible cards for clear, sequential visibility matching loading orders.[/*]
  [*] [b]Active Mod Registries Content Summary[/b]: Added a collapsible bottom registry indexing all active row edits and engine hook signatures per mod, with dynamic type badges (UE4SS, PalSchema, Hybrid), and supporting 2-column grid rendering.[/*]
  [*] [b]Configuration & Asset Exclusions[/b]: Excludes asset-only mods (.pak / .ucas / .utoc files) and internal manager metadata (.pmm.json) from the scanning registry.[/*]
  [*] [b]Dynamic Hybrid Path Resolution[/b]: Automatically scans and associates both physical deployment folders (the main UE4SS directory and the PalSchema/mods/ subdirectory) for Hybrid mods, resolving content correctly.[/*]
  [/list][/*]
[*] [b]Internal Database Inspector & Editor[/b]: Added a new [b]DB[/b] workspace tab for advanced users to inspect and debug the live application state.
  [list]
  [*] [b]Dynamic Tabbed Data Grid[/b]: Supports browsing active tables (Mods, Profiles, and Settings) via an interactive grid layout.[/*]
  [*] [b]Live Raw JSON Editor[/b]: Edit selected database records with inline validation to ensure proper format before saving.[/*]
  [*] [b]Re-scan Integration[/b]: Prompting confirmation modal after saving edits to trigger a full mod directory re-scan to immediately reflect changes.[/*]
  [/list][/*]
[*] [b]Top-Right Toast Alerts[/b]: Relocated toast notifications to the top-right corner to prevent overlapping with packer footer controls, adding a smooth slide-down animation and border shadows.[/*]
[*] [b]Warning Toast Alert Level[/b]: Added warning toasts featuring warning-tailored dark/orange aesthetics and union type support in TypeScript.[/*]
[/list]
